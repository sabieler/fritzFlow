            FRITZ!Box verbinden

            Die Zugangsdaten bleiben auf diesem Rechner und werden nur an deine FRITZ!Box geschickt.

            Empfohlen: eigenen FRITZ!Box-Benutzer für FritzFlow anlegen
            1. Öffne die FRITZ!Box-Oberfläche und gehe zu System → FRITZ!Box-Benutzer → Benutzer hinzufügen.
            2. Name z. B. fritzFlow, ein eigenes Passwort vergeben.
            3. Recht „FRITZ!Box Einstellungen“ anhaken – zwingend für den Paketmitschnitt.
            4. Kein „Zugang aus dem Internet“ erlauben.
            5. Speichern (evtl. an der Box per Taste bestätigen) und Benutzer und Passwort hier eintragen.

            So bleibt dein Admin-Zugang unberührt, und der Zugang lässt sich jederzeit sperren.

            Demo-Modus: Die Einstellungen sind schreibgeschützt.
            Detailgrad (Last auf der FRITZ!Box)
            So viele Bytes je Paket schickt die Box. Weniger bedeutet weniger Last, mehr bedeutet mehr erkannte Hostnamen. Paketinhalte werden nie ausgewertet.
