# Sicherheit

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue, sondern vertraulich über
**[Security → Report a vulnerability](https://github.com/sabieler/fritzFlow/security/advisories/new)**.

Hilfreich sind: betroffene Version (`fritzflow -version`), Betriebssystem, eine kurze Beschreibung
und – falls möglich – Schritte zum Nachvollziehen. Bitte keine echten Mitschnitte, Passwörter oder
andere persönliche Daten mitschicken.

Unterstützt wird jeweils die [neueste Version](https://github.com/sabieler/fritzFlow/releases/latest).
FritzFlow ist ein Freizeitprojekt; ich melde mich so bald wie möglich.

---

Please report security issues privately via **Security → Report a vulnerability** instead of a
public issue.
